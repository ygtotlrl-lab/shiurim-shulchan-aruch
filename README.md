# שיעורים — סריקות שולחן ערוך הרב

מאגר קבצים של אפליקציית [שיעורים](https://github.com/ygtotlrl-lab/shiurim), ואין בו קוד. GitHub Pages מגיש אותו, והאפליקציה קוראת ממנו.

כל עמוד — תמונה מוכנה בתקן אחד: PNG שחור-לבן (1 ביט), ברוחב 1600 פיקסלים, קובץ לכל עמוד.

- `sa1/` — חלק א.
- `sa2/` — חלק ב.
- `sa34/` — חלקים ג–ד.
- `sa56/` — חלקים ה–ו.

מאגר לכל לימוד, נפרד מהאפליקציה — האתר מוגבל ל-1GB, והסריקות שוקלות את רובו.

שמות התיקיות: התיקייה הראשית — קוד הספר, 2–4 אותיות לטיניות משמו העברי, ובספר רב־כרכים הקוד ומספר הכרך; השלמה מדפוס אחר — תיקייה משלה: קוד התיקייה שהיא משלימה ואות המקור (`g` מקראות גדולות · `v` ויניציאה · `x` עותק אחר של אותו דפוס · `l` וילנא · `t` תר״ס · `s` סריקה כפולה שפוצלה לשני עמודיה המודפסים); שם הקובץ — מספר העמוד בסריקת המקור.
